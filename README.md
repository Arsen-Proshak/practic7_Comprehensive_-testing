# Практична робота № 6–7: Проєктування станів екрана, дизайн-токени та QA-аудит веб-додатку

## Опис проєкту
Інтерактивний веб-додаток «Каталог навчальних модулів», реалізований на чистому JavaScript (ES6+) та нативних CSS Custom Properties без сторонніх фреймворків. Проєкт демонструє життєвий цикл станів інтерфейсу (`Loading`, `Content`, `Empty`, `Error`), трирівневу систему дизайн-токенів (`Primitive`, `Semantic`, `Component`), підтримку світлої/темної тем та комплексний інженерний аудит якості.

## Аудит адаптивності та Chrome DevTools Lighthouse

### 1. Перевірка адаптивності (Responsive Testing)
* **375 px (Mobile):** картки шикуються в 1 колонку, елементи панелі керування переносяться без накладання, горизонтальна прокрутка відсутня.
* **768 px (Tablet):** сітка адаптується у 2 колонки, поля форми вирівнюються коректно.
* **1440 px (Desktop):** контент центрується у контейнері `960px` із сіткою у 3 колонки.

### 2. Результати автоматизованого аудиту (Lighthouse — Desktop/Mobile)
* **Accessibility:** `100 / 100` (наявні прив'язані `<label>`, семантичні `<button>`, коректні `aria-*` атрибути та контрастність WCAG AA).
* **Best Practices:** `100 / 100` (відсутні помилки в консолі, безпечна маніпуляція DOM без `innerHTML`, коректний `DOCTYPE` та кодування).
* **SEO:** `100 / 100` (наявні `<title>`, `<meta name="description">`, `<meta name="viewport">` та семантична ієрархія заголовків).
